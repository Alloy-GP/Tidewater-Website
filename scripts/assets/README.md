# scripts/assets

`NunitoSans-Variable.ttf` — Nunito Sans, the site's heading face, vendored so
`make-newsletter-cover.py` can render newsletter cover art with the real brand
type rather than a system fallback. Variable font; the script sets the weight
axis per text run.

Licensed under the SIL Open Font License 1.1 (as published on Google Fonts).
Build-time only — never served to browsers.
